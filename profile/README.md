<h1 align="center">The Lupaxa Git Hooks Toolbox</h1>

**The Lupaxa Git Hooks Toolbox** contains Git hooks, libraries and supporting utilities for improving code quality and automating development workflows.

The organisation focuses on providing reliable, well-documented and reusable Git hooks that help developers enforce coding standards, improve security and
maintain consistent quality throughout the software development lifecycle.

## Focus

**The Lupaxa Git Hooks Toolbox** contains tools for areas including:

- Pre-commit and pre-push hooks
- Code quality and linting
- Automated testing
- Security and secret scanning
- Commit message validation
- Repository policy enforcement
- Build and release validation
- Developer workflow automation

Whether you're enforcing coding standards, preventing common mistakes, automating quality checks or improving the consistency of your development workflow,
**The Lupaxa Git Hooks Toolbox** aims to provide practical, reusable tools that simplify working with Git hooks.
